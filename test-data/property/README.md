# Property and Model Seeds

Store deterministic seeds and minimized reference-model counterexamples here.

`domain-stage-three-v1.steps` is generated by
`scripts/generate-stage-three.py`. It pins the generator version, 256-seed
range, 64-step bound, after-every-step snapshot cadence, and retained replay
prefixes used by the Stage 03 production/reference comparison. Model failures
print a `REGRESSION` record that can be added to this generated corpus. Each
generated round includes client-ordered mixed-direction MODE vectors and full
invitation-principal, revision, and expiry comparisons.
